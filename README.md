# 以 AI 驅動之即時動態水帳本｜系統模擬

把研究區域視為一個需要持續結算的水資源帳戶，用 AIoT 感測器持續記帳，再以 AI 做趨勢預測與分級預警。本專案是系統模擬原型，所有資料皆為模擬產生。

**期初結餘 ＋ 收入 － 支出 ＝ 期末結餘**

## 頁面

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 首頁 |
| `dashboard.html` | 水帳本儀表板：感測器與品質旗標、帳本結算與閉合差、AI 分級預警與建議式決策 |
| `lake.html` | 3D 模擬環境（研究區域）：山區水庫、埤塘群與農地、下游河川與滯洪池、地下水井區；點擊區域放大，各區有獨立的水位、帳本與感測器 |

每個頁面都是單一 HTML 檔，不需要建置或安裝套件；3D 場景已內嵌 three.js r149（MIT License），離線也能開啟。

## 本機開啟

直接用瀏覽器開啟 `index.html`，或在此資料夾執行：

```bash
python -m http.server 8000
# 開啟 http://localhost:8000
```
